ordito.parametrization

Flatten a mesh into the plane: harmonic, Tutte, ARAP, SLIM and LSCM parametrizations.

Seven maps, differing in what they hold fixed and what they minimize. The first three pin the boundary and solve for the interior: harmonic minimizes Dirichlet energy with cotangent weights, tutte is the same solve with uniform weights (guaranteeing an injective map for a convex boundary), and arap alternates local rotation fits with a global solve to trade conformality for low area distortion. slim frees the boundary and refines a start toward the least symmetric Dirichlet distortion, never inverting a face the start had the right way round and not squashed flat. lscm instead pins only two vertices and lets the boundary find its own shape, minimizing conformal rather than Dirichlet energy. low_distortion_parametrization pins nothing and needs no start: a free-boundary chart of low ARAP distortion in the mesh's own units for an open surface of any topology, converged on a coarse mesh; arap_parametrization is the same chart refined from a harmonic, Tutte or LSCM map of a surface with a boundary. slim_parametrization unwraps in one call to the least symmetric Dirichlet distortion, from the free chart or a harmonic, Tutte or LSCM start.

map_vertices_to_circle supplies the boundary condition the fixed-boundary three need, and face_flipped_indices is the diagnostic that says whether a result is actually injective. All but the two low-distortion charts port the corresponding igl:: routines.

The fixed-vertex maps (harmonic, tutte, lscm) take the mesh as an ordito.mesh.Trimesh or as its vertices and faces. Their solves iterate, verified, and fall back to a sparse Cholesky factorization where the iteration fails; given a Trimesh, a factorization is kept on it (Trimesh.fixed_vertex_solver), and one built ahead with FixedVertexSolver.factor -- or by a call with solver="direct" -- turns every later call fixing the same vertices into a factored solve with no iteration.

FixedVertexSolver 

FixedVertexSolver(mesh: Trimesh)

Factorizations of the fixed-vertex maps' systems on one mesh, kept by the mesh.

What Trimesh.fixed_vertex_solver returns, and what harmonic, tutte and lscm consult when given a Trimesh. Each map solves the system its operator reduces to once the fixed vertices are eliminated, and that system depends on which vertices are fixed -- not on the values they are fixed to -- so one factorization per (method, k) serves every later call that fixes the same vertices: such a call runs no iteration, only the factorization's solve.

A factorization is kept here when factor builds it ahead of the calls, when a call asks for one (solver="direct"), or when a call built one anyway: the iteration's result failed its verification (see min_quad_with_fixed), or the system is factored from the start -- at k >= 3, for a k == 2 harmonic / tutte system or an lscm one on a mesh of 4 000 vertices or more, and on the CPU device for a k == 1 one on a mesh of 5 000 or more. A call fixing other vertices than the kept factorization's solves as if none were kept, and replaces it with its own when it builds one. A system factored from the start that cannot be factored (over CHOLESKY_MEMORY_BUDGET, or not definite) is remembered as such until release, and later "auto" calls iterate without attempting it again.

Notes

A kept factorization holds device memory of the order of its system's fill-in for as long as this solver lives -- the mesh's lifetime -- reported by nbytes and returned by release or Trimesh.release_factorizations. The solver refers to its mesh weakly and is unusable once the mesh is gone.

See Also

Trimesh.fixed_vertex_solver MinQuadWithFixedData

Examples:

Factor once for a boundary, then every harmonic map of that mesh fixing it is a direct solve:

import ordito as od

vertices, faces = od.creation.sphere_cap(angle=1.0, subdivisions=3)
mesh = od.mesh.Trimesh(vertices, faces)
boundary = od.boundary.longest_boundary_loop(vertices, faces)
solver = mesh.fixed_vertex_solver()

uv = od.parametrization.harmonic(mesh, boundary_indices=boundary, boundary_uv=circle)

def factor(self, method: str, fixed_indices: wp.array[wp.int32], *, k: int = 1) -> bool:
    """
    Factor ``method``'s system with ``fixed_indices`` fixed, for every later call fixing them.

    Parameters
    ----------
    method
        ``"harmonic"``, ``"tutte"`` or ``"lscm"``: the map the factorization serves.
    fixed_indices
        ``(n_fixed,)`` the vertices the calls fix: ``boundary_indices`` of
        [`harmonic`][ordito.parametrization.harmonic] / [`tutte`][ordito.parametrization.tutte],
        ``pinned_indices`` of [`lscm`][ordito.parametrization.lscm]. Only the set matters,
        not the order.
    k
        The harmonic power the calls pass (``1`` for ``"lscm"``).

    Returns
    -------
    bool
        Whether the calls will run no iteration: ``False`` when the system cannot be factored
        (over [`CHOLESKY_MEMORY_BUDGET`][ordito.cholesky.CHOLESKY_MEMORY_BUDGET], or not
        definite in ``float64``), and they keep iterating.

    Raises
    ------
    ValueError
        If ``method`` is not one of the three, if ``k < 1``, if ``k != 1`` for ``"lscm"``, or
        if ``fixed_indices`` repeats a vertex or holds one outside ``[0, n_vertices)``.
    RuntimeError
        If ``fixed_indices`` is not on the mesh's device.

    Examples
    --------
    ```python
    import ordito as od

    vertices, faces = od.creation.sphere_cap(angle=1.0, subdivisions=3)
    mesh = od.mesh.Trimesh(vertices, faces)
    boundary = od.boundary.longest_boundary_loop(vertices, faces)
    print(mesh.fixed_vertex_solver().factor("tutte", boundary, k=2))  # True
    ```
    """
    _require_fixed_vertex_method(method, k, "FixedVertexSolver.factor")
    mesh = self._bound_mesh()
    require_same_device(vertices=mesh.vertices, fixed_indices=fixed_indices)
    n_vertices = mesh.n_vertices
    if n_vertices == 0:
        return True
    n_fixed = fixed_indices.size
    # The values are scattered into a buffer the factorization never reads.
    no_uv = _launch.empty(n_fixed, dtype=wp.vec2, device=mesh.device)
    if method == "lscm":
        fixed_mask, _ = _pin_stacked(n_vertices, fixed_indices, no_uv, mesh.device)
        n_fixed *= 2
    else:
        fixed_mask, _ = _scatter_constraints(n_vertices, fixed_indices, no_uv, mesh.device)
    system, _ = _fixed_vertex_system(mesh, method, k, fixed_mask, n_fixed, factor=True)
    if system.factored:
        self._keep(method, k, system)
    return system.factored or system.n_free == 0

face_flipped_mask(

Per-face flag: whether a triangle is inverted (negative 2D signed area) in the parametrization.

For each triangle the 2D signed area of its three UV vertices is computed; a face is flagged True when that area is strictly negative, i.e. the triangle has folded over (flipped orientation) in the 2D domain. Mirrors libigl's flipped_triangles per-triangle test (determinant of the homogeneous 3 x 3 vertex matrix < 0). Degenerate (zero-area) triangles are not flagged, matching the strict < 0 comparison. face_flipped_indices is the index form of this mask.

Notes

Equivalent to the per-triangle predicate behind libigl flipped_triangles: the 2D cross product (v1 - v0) x (v2 - v0) equals det([[x0, x1, x2], [y0, y1, y2], [1, 1, 1]]), so a True entry corresponds exactly to a triangle libigl would list as flipped.

This is a different flip from face_flip_mask, which is about the 3D winding: this mask flags a triangle whose UV image has folded over, a property of the parametrization that says nothing about the surface, while that one flags a triangle whose index order must be reversed to agree with its patch. A mesh can be consistently wound and still have flipped UVs, and vice versa.

    Matches ``igl::harmonic`` at ``k == 1``. Above, igl's default mass matrix is the Voronoi one
    where this uses the barycentric lumped mass; ``igl::harmonic`` given a barycentric
    ``massmatrix`` is the same map.

    Each ``k`` is solved its own way, since raising the operator to the ``k``-th power raises its
    condition number to it. ``k == 1`` runs conjugate gradient under the Jacobi-Chebyshev polynomial
    ([`chebyshev_preconditioner`][ordito.linalg.chebyshev_preconditioner]), ``k == 2`` under the
    square of that Laplacian's polynomial
    ([`squared_laplacian_preconditioner`][ordito.linalg.squared_laplacian_preconditioner]) -- on a
    mesh of fewer than 4 000 vertices; from 4 000 the ``k == 2`` system is factored at once, as
    ``k >= 3`` is below, its iteration growing faster with the mesh than the factorization. Both
    results are verified -- converged within
    [`CG_FACTOR_AFTER_POLYNOMIAL_ROUNDS`][ordito.linalg.CG_FACTOR_AFTER_POLYNOMIAL_ROUNDS] rounds,
    with a componentwise
    backward error under
    [`VERIFIED_BACKWARD_ERROR`][ordito.linalg.VERIFIED_BACKWARD_ERROR] -- and a result that is not
    is replaced by a [`sparse_cholesky`][ordito.cholesky.sparse_cholesky] solve: on a strongly
    graded mesh the ``k == 2`` system's condition number nears the reciprocal of ``float64``'s
    precision, where no iteration converges. ``k >= 3`` is factored from the start, the iteration
    (under the multigrid preconditioner
    [`multigrid_preconditioner`][ordito.linalg.multigrid_preconditioner]) taken only when the
    system cannot be factored; a `Trimesh` remembers that refusal, so its later calls iterate
    without attempting the factorization again. Given a `Trimesh`, a factorization built here is
    kept on it, and one prepared with
    [`FixedVertexSolver.factor`][ordito.parametrization.FixedVertexSolver.factor] serves every
    later call fixing the same vertices -- whatever their values -- with no iteration; the
    ``vertices, faces`` form drops it, and says so at ``INFO``.

    On such an ill-conditioned system the answer itself is determined only to the system's own
    precision: direct solvers under different orderings agree to about a percent of the UV range
    there, as this one does with them.

    ```

    uv = od.parametrization.arap(vertices, faces, boundary, circle, uv_init)
    print(od.parametrization.face_flipped_indices(uv, faces).shape)  # (0,)
    print(np.array_equal(uv.numpy()[boundary.numpy()], circle.numpy()))  # True
    ```
    """
    require_same_device(
        vertices=vertices,
        faces=faces,
        fixed_indices=fixed_indices,
        fixed_uv=fixed_uv,
        uv_init=uv_init,
        pattern=None if pattern is None else pattern.offsets,
    )
    if max_iterations < 1:
        raise ValueError(f"arap max_iterations must be >= 1, got {max_iterations}.")
    if tolerance <= 0.0:
        raise ValueError(f"arap tolerance must be > 0, got {tolerance}.")
    device = vertices.device
    n_vertices = vertices.size
    if n_vertices == 0:
        return _launch.empty(0, dtype=wp.vec2, device=device)

    # Interior vertices with nothing pinned leave the ARAP global system translation-invariant
    # (singular) -- and since n_vertices > 0, an empty ``fixed_indices`` always means at least one
    # interior vertex exists. Checked before the cotangent/Laplacian build below (mirroring
    # harmonic / tutte), so a rejected call doesn't pay for the assembly first.
    _require_fixed_vertices(
        fixed_indices.size,
        n_vertices,
        1,
        "arap requires at least one fixed vertex when the mesh has interior vertices; the ARAP "
        "global system is otherwise singular (translation invariant).",
    )
    n_faces = faces.size // 3

    laplacian = cotmatrix(vertices, faces, dtype=wp.float64, pattern=pattern)

    # Partition vertices into pinned (fixed) and interior (free), and extract the global-step
    # operator with it: the interior block of Q = -L and the constant boundary term -(-L)_ub bc.
    # ``fixed_values`` is the (2, n_vertices) prescribed-UV buffer (row 0 = u, row 1 = v) shared
    # with the assembly / scatter kernels; ``interior_map`` compacts free vertices into the reduced
    # system.
    # ``future work``: libigl also supports rotation groups ``G`` (shared rotations across grouped
    # faces, replacing the per-face fit with a group-summed covariance) and ``with_dynamics`` (a
    # mass-matrix + timestep term added to Q and the right-hand side); both are out of scope here.
    fixed_mask, fixed_values = _scatter_constraints(n_vertices, fixed_indices, fixed_uv, device)
    fixed_values_2d = odt.as_array2d(fixed_values, wp.float64)
    q_uu, rhs_const, interior_map, n_interior = twl.partitioned_interior_system(
        laplacian, fixed_mask, fixed_values_2d, scale=-1.0
    )
    # The scatter skips an out-of-range index and a repeated one marks its vertex once, so either
    # leaves fewer vertices fixed than ``fixed_indices`` lists: the free count just read shows it.
    if n_vertices - n_interior != fixed_indices.size:
        raise ValueError(
            "arap: fixed_indices must be distinct vertex indices in [0, n_vertices); they fix "
            f"{n_vertices - n_interior} vertices where {fixed_indices.size} were given"
        )

    out_uv = _launch.empty(n_vertices, dtype=wp.vec2, device=device)
    if n_interior == 0:
        # Every vertex pinned: the prescribed positions are the whole answer, and the loop's
        # setup would serve no solve.
        empty_sol = _launch.zeros((2, 0), dtype=wp.float64, device=device)
        _launch.launch(
            kernel_parametrization.scatter_solution,
            dim=n_vertices,
            inputs=[fixed_mask, interior_map, empty_sol, fixed_values_2d, out_uv],
            device=device,
        )
        return out_uv

    # The loop's buffers, none allocated inside it: each face's gradients and area, the
    # warm-started solution per column ``sol`` (seeded from ``uv_init``'s free rows by the same
    # launch) and the global step's right-hand side ``b``, the last two in one allocation.
    vertex_faces, offsets = od.adjacency.vertex_face_adjacency(faces, n_vertices=n_vertices)
    gradients = odt.empty_2d((n_faces, 3), wp.vec2d, device=device)
    areas = _launch.empty(n_faces, dtype=wp.float64, device=device)
    solve_buffers = _launch.empty(4 * n_interior, dtype=wp.float64, device=device)
    sol = odt.as_array2d(
        _launch.view(solve_buffers, 0, 2 * n_interior).reshape((2, n_interior)), wp.float64
    )
    b = odt.as_array2d(
        _launch.view(solve_buffers, 2 * n_interior, 4 * n_interior).reshape((2, n_interior)),
        wp.float64,
    )
    _launch.launch(
        kernel_parametrization.arap_setup,
        dim=max(n_faces, n_vertices),
        inputs=[vertices, faces, fixed_mask, interior_map, uv_init],
        outputs=[gradients, areas, sol],
        device=device,
    )

    # One batched CG state for both UV columns, reading ``b`` and warm-started from ``sol``. The
    # global steps are short warm-started Jacobi-Chebyshev solves of an operator rebuilt per call,
    # so it factors only once they are found long (``_ARAP_FACTOR_FROM_ROUNDS_CUDA`` / ``_CPU``).
    solver = twl.spd_column_solver(
        q_uu, b, sol, tol=tolerance, maxiter=10 * n_interior, preconditioner="chebyshev",
        factorize=False,
    )  # fmt: skip

    held = None
    for iteration in range(max_iterations):
        # The local step and the global step's right-hand side at each free vertex.
        _launch.launch(
            kernel_parametrization.arap_rhs,
            dim=n_vertices,
            inputs=[faces, vertex_faces, offsets, gradients, areas, fixed_values_2d, fixed_mask,
                    interior_map, sol, rhs_const],
            outputs=[b],
            device=device,
        )  # fmt: skip
        # Both UV columns in one batched symmetric-PD solve, warm-started from the previous ``sol``;
        # by a factorization of the operator once the iteration is found long.
        if held is not None:
            held.solve(b, sol, tol=tolerance)
            continue
        rounds, _, _ = solver()
        if iteration == 1 and iteration + 1 < max_iterations:
            # The second solve's round count, read once a call: it predicts the later solves'
            # length (the first, from ``uv_init``, does not: a harmonic start's first solve can be
            # long and every later one short), which decides whether a factorization pays.
            remaining = max_iterations - iteration - 1
            if _round_count(rounds) * remaining >= (
                _ARAP_FACTOR_FROM_ROUNDS_CUDA
                if wp.get_device(device).is_cuda
                else _ARAP_FACTOR_FROM_ROUNDS_CPU
            ):
                held = _arap_factorization(q_uu, vertices, fixed_mask, interior_map)
    if held is not None:
        held.release()
    # The full UV field, the pinned rows at their constraints.
    _launch.launch(
        kernel_parametrization.scatter_solution,
        dim=n_vertices,
        inputs=[fixed_mask, interior_map, sol, fixed_values_2d, out_uv],
        device=device,
    )
    return out_uv

Free-boundary chart of least symmetric Dirichlet distortion, refined from a start (SLIM).

Minimizes sum_f A_f (s1^2 + s2^2 + s1^-2 + s2^-2) over the chart, s1 and s2 each face's singular values, by scalable locally injective maps: each iteration solves the energy's reweighted ARAP proxy, whose gradient at the current chart is the energy's own, and moves along that step only as far as no face inverts and the energy does not rise. The energy grows without bound as a face collapses, so it trades stretch against compression evenly and never folds a face the start had the right way round (and not squashed flat, below). No vertex is pinned and the boundary is free; the chart keeps the start's position and rotation up to the drift of its optimization.

The start must be a chart of the mesh in its own units (a free chart such as low_distortion_parametrization, or a disk map such as tutte scaled to the surface's area): the energy is not scale-invariant, and its minimum is an isometry wherever one exists. A start winding clockwise on the whole is refined mirrored and returned with its winding. A face inverted in the start, as a surface with a handle forces somewhere, is held by the ARAP term 4 A_f |J_f - R_f|^2 instead, which has no barrier and may right it; so is a face the start squashes by more than a thousandfold, which the barrier, held at the edge of float64, would freeze.

    search keeps descending; libigl refactors every iteration. The proxy's weights are capped

        or faces.size % 3 != 0
        or uv_init.dtype is not wp.vec2
        or uv_init.size != vertices.size

            f"a wp.vec2 uv_init of one entry per vertex, got {vertices.size} "
            f"{vertices.dtype.__name__} vertices, {faces.size} {faces.dtype.__name__} faces and "
            f"{uv_init.size} {uv_init.dtype.__name__} uv_init"
        )

        raise ValueError(f"slim max_iterations must be >= 0, got {max_iterations}")

    # stiffness pattern, the step and its right-hand side, and a slot (or partials buffer) per
    # iteration for the step bound, the trial energies, the accepted step and its energy.
    vertex_faces, vertex_offsets = od.adjacency.vertex_face_adjacency(faces, n_vertices=n_vertices)
    metric = _launch.empty(n_faces, dtype=wp.mat22d, device=device)

    )

        _launch.view(steps, max_iterations, 3 * max_iterations),
    )
    # The step bound and the trial energies fold a face a lane where the device allows.
    trial_width, trial_blocks = kernel_reduce.spanned_blocks_1d(n_faces, device)
    partial_size = _launch.block_partials_size(trial_blocks, 1)
    partials = _launch.zeros(
        partial_size * max_iterations,
        dtype=kernel_parametrization.slim_trials_vector,
        device=device,
    )
    factorization: od.cholesky.SparseCholesky | None = None
    for iteration in range(max_iterations):
        _launch.launch(
            kernel_parametrization.slim_face_terms,
            dim=n_faces,
            inputs=[chart, faces, gradients, areas, inverted],
            outputs=[metric, force],
            device=device,
        )
        if iteration % _SLIM_REFACTOR_EVERY == 0:
            _launch.launch(
                kernel_parametrization.slim_block_values,
                dim=n_keys,
                inputs=[offsets, starts, order, gradients, metric, anchor, wp.int32(n_vertices)],
                outputs=[blocks.values],
                device=device,
            )
            expanded = od.array.scalar_expansion(blocks)
            if factorization is None:
                assert analysis is not None
                factorization = analysis.with_expanded_operator(expanded)
                # The scalar analysis has served: the proxy's factorization holds its own.
                analysis = None
                # Every iteration solves into the same two buffers: recorded once, replayed.
                factorization.records_at_once = True
            else:
                factorization.refactor(expanded)
        assert factorization is not None
        _launch.launch(
            kernel_parametrization.slim_rhs,
            dim=n_vertices,
            inputs=[faces, vertex_faces, vertex_offsets, gradients, force],
            outputs=[rhs],
            device=device,
        )
        # The held factor's direction is all a step needs: the line search below decides how far
        # to move, so refining it against the proxy would buy nothing.
        factorization.solve(rhs_flat, step_flat, refine=False)
        _launch.launch_tiled(
            kernel_parametrization.slim_step_bound,
            dim=trial_blocks,
            inputs=[chart, step, faces, gradients, inverted, iteration, trial_width],
            outputs=[bounds],
            block_dim=TILE_1D,
            device=device,
        )
        trial_partials = _launch.view(
            partials, iteration * partial_size, (iteration + 1) * partial_size
        )
        _launch.launch_tiled(
            kernel_parametrization.slim_trial_energies,
            dim=trial_blocks,
            inputs=[chart, step, faces, gradients, areas, inverted, bounds, iteration, trial_width],
            outputs=[trial_partials],
            block_dim=TILE_1D,
            device=device,
        )
        _launch.launch(
            kernel_parametrization.slim_accept,
            dim=1,
            inputs=[trial_partials, bounds, wp.int32(iteration)],
            outputs=[accepted, energies],
            device=device,
        )
        _launch.launch(
            kernel_parametrization.slim_advance,
            dim=n_vertices,
            inputs=[step, accepted, wp.int32(iteration), chart],
            device=device,
        )
        if (iteration + 1) % _SLIM_REFACTOR_EVERY == 0 and iteration + 1 < max_iterations:
            # Read back: whether the period's iterations still lowered the energy decides whether
            # to issue more (read where the next refactor reads its pivots anyway).
            first = 2 * (iteration + 1 - _SLIM_REFACTOR_EVERY)
            period = read_values(energies, first, 2 * _SLIM_REFACTOR_EVERY)
            if float(period[0]) - float(period[-1]) <= tolerance * float(period[-1]):
                break
    _launch.launch(
        kernel_parametrization.slim_uv,
        dim=n_vertices,
        inputs=[chart, start_areas],
        outputs=[out_uv],
        device=device,
    )
    return out_uv

    Notes
    -----
    The unknowns are stacked ``[u; v]`` (all ``u`` DOFs then all ``v`` DOFs), matching igl's
    ``lscm``: pin ``i`` fixes DOF ``i`` (``u``) and DOF ``i + n_vertices`` (``v``). The returned
    ``Q`` of ``igl.lscm`` equals ``-repdiag(L, 2) - 2 A`` exactly (see
    [`lscm_hessian`][ordito.energies.lscm_hessian]).

    Examples
    --------
    A flat grid with two opposite corners pinned where they are: the identity map is conformal, so
    LSCM recovers it:

    ```python
    import numpy as np
    import warp as wp

    import ordito as od

    vertices, faces = od.creation.grid(count=(6, 6))
    pinned = wp.array([0, 35], dtype=wp.int32)
    pinned_uv = wp.array(vertices.numpy()[[0, 35], :2], dtype=wp.vec2)
    uv = od.parametrization.lscm(
        vertices=vertices, faces=faces, pinned_indices=pinned, pinned_uv=pinned_uv
    )
    print(uv.shape)  # (36,)
    print(np.allclose(uv.numpy(), vertices.numpy()[:, :2], atol=1e-5))  # True
    ```
